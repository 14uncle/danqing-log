## 专业版新增

### 多文件合并时间线

把多个日志文件按时间戳合成**一条时间线**：

- **每源时钟偏移校准**（±10 年 / 时区 ±23h）—— 各机器时钟对不齐不再是问题
- **按源着色 / 按源隐藏**；`req_id` 一键跨源追踪（1699 万行扫描 164–168 ms）
- 源还在写就**增量合流**（27–50 ms / 4 MiB）
- 实测：3 源 × 1 GiB（1698 万行）合并就绪 **约 0.95 秒**

### 字段分析

点一个 JSONL 字段即出分布：数值给 p50 / p99 与区间（超 100 万值时标「采样估计」），
枚举给 Top20 + 其他桶；作用域跟随当前过滤行集。1 GiB 全文件单列约 **1 秒**。

### 导出

当前过滤结果导出**原始行 / pretty JSON / CSV**（BOM + CRLF + RFC4180，Excel 直接打开不乱码），
流式执行、可取消、不留半成品。1 GiB 原始行导出 **608 ms**。

### 命名工作台会话

过滤器组合 + 搜索历史 + 列配置 + 展开状态，存成命名工作区，跨重启恢复。

### 以及这三件（也属专业版）

- **列配置**：列宽拖拽、显隐、重排，按文件记忆
- **书签跨重启持久化**（会话内书签仍免费）
- **免语法字段查询**：点选字段与算符、只打值，自动拼进过滤
