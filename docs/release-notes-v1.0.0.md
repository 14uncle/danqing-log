## 这一版有什么

- **打开**：启动传参 / `Ctrl+O`；异步索引，GB 级文件全程可响应，底栏显示
  `{pct}% · {done}/{total} MiB`，索引中可取消，或直接开另一个文件
- **滚动**：行锚定虚拟视口（不建全量行偏移表），2 亿像素域不失真
- **搜索**：正则全文扫描，**默认大小写不敏感**（`error` 命中 `ERROR`，要精确匹配写 `(?-i)`），
  可见区高亮 + 命中逐跳导航
- **tail 跟随**：250 ms 节流轮询，新行 ≤1 s 出现；上滚自动脱离，外部截断 / 轮转自动重建
- **JSONL 表格**：自动检出 → 列发现 → 列化表格；嵌套对象以子行展开；字段过滤迷你语法
  （`level=ERROR status=50*`，空格 AND，尾缀 `*` 前缀通配）跑在工作线程，不冻界面
- **编码**：UTF-8（含 BOM）/ UTF-16 LE·BE（有无 BOM 均可）/ GBK（原字节索引 + 行级解码，
  中文可搜）/ 其余单字节编码 Latin-1 兜底
- **级别统计侧栏**：6 桶计数（FATAL / ERROR / WARN / INFO / DEBUG / 其他）+ 对数刻度横条；
  JSONL 下点柱条即筛出该级别，`Ctrl+L` 显隐
- **选区 / 复制**：双击选词走混合连接器规则 —— 时间戳 / IP / `level=ERROR` / 路径 / URL
  **整选**，英文按单词断开，中文逐字；拖动框选字符级、可跨行、可跨展开子行。
  `Ctrl+C` 按 **「文本选区 > 单元格 > 行选中」** 取内容：表格里双击单元格拿**完整值**
  （不受列宽截断省略影响），选中行拿整行原文，展开块里选子行拿该子行 `label = value`

## 已知边界

- UTF-16 转码副本内存翻倍（1 GB → 约 500 MB 副本）；>2 GB 文件未验证
- JSONL 列化只认扁平顶层字段；嵌套对象以子行展开看，不进列
- GBK / Latin-1 文件搜索退化为字面量（无正则语法）
- 表格模式列无拖拽 / 显隐 / 重排（v1 欠账，在免费层补）
- 级别侧栏在明文日志下**只读**（纯文本模式没有字段过滤语法，点柱条无法给出等价筛选），
  侧栏顶部有「仅统计·不可点选」提示
- 直方图的 DEBUG/TRACE 合并为一行，故该行与「其他」行不可点
- 搜索命中上限 100 万条（超出时底栏标注总命中数）；书签为会话内，不持久化
- 不做 ANSI 转义渲染（按级别着色是另一回事）
