## 附：免费软件生存三模型的农场思考（2026-10-09 闲聊沉淀，用户「go」落档）

背景：由「Ditto 免费如何生存」起的闲聊，对照三模型——Ditto（成本归零爱好型：单人 2004 年维护至今，全免费，工资自补贴）/ Obsidian（服务抽税独立生意型：Dynalist Inc.，3 工程师 0 融资撑 1.5M 月活，免费核心 + Sync/Publish/Catalyst 可选服务收费，2024-11 起商用也免费）/ VS Code（大厂战略武器型：直接收入零，账记在 Copilot/Azure/GitHub，commoditize your complement）——提炼出对空窗三件活（尤其分发准备）的直接输入。

- **定位一句话**：Ditto 是农场的**地板**（成本≈0、工资自补贴、不可被杀死——0 单也活着），Obsidian 是**天花板**，VS Code 是**天敌**。农场自己的活法是第四种：**免费层是仪器，读数是产品**——装置要求信号可测（埋点）/ 有期限（校准钟）/ 可证伪（失效标志）；读数小该挪仪器的位置（分发），不是砸仪器。
- **付费层形态不可照抄 Obsidian**：它能收租是因为有可计量服务（同步/发布持续吃服务器资源，订阅天经地义）；农场架构零后端、无可计量资源，**买断是被架构强制的而非定价偏好**——09-27「永久买断+身份门」裁定正确。
- **分发材料的主角**（直接喂 `docs/distribution-prep.md`）：Obsidian 的增长引擎是平台面（插件/主题/内容创作者建立在它上面），农场产品是封闭工具没有这个面；单人开发者的替代品 = **用户创造的内容**——发稿主角不是功能清单，是「我用它在 2GB 日志里抓到线上 bug」式的使用故事。
- **10x 尺子**：Sublime 在 VS Code 免费武器下存活，证明买断 indie 可活——前提是长板 10 倍且用户每天摸得到。log viewer 唯一的 10x = **GB 级 mmap 秒开**，所有分发材料必须以它为绝对主角；pomodoro 的差异是审美/动效，是品味不是 10x。
- **系统吸收距离**（天敌的将来时）：Windows 小工具品类的特有死法——clipboard←Win+V、tile←PowerToys/Snap、pomodoro 计时层被 Focus Sessions 部分吸收；log viewer 离 OS checkbox 远（专业工具），结构上比前几件产品安全。该问话同日已显式化进农场根 CLAUDE.md 调研三闸。
- **时间轴校准**：Obsidian 发布到爆发约 2 年，Ditto 成为默认答案用了十几年；农场的时钟测的是 30 天基线，管不了 2 年的问题——仪器读数 ≠ 终审判决，但「慢热」也不是逃避读数的借口。
