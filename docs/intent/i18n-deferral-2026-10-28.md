## 1. 问句与裁决

**问**：LogLens 要不要加中英文切换？
**裁**：**不加**（现在）。走 **B 序**——海外触点英文化 + 小剂量海外提交站试投先行
（几天的活）；UI i18n 本体挂钟等读数（7500 处字符串抽离 = 几周工时，不在零海外流量时预付）。

## 2. 证据账（裁决依据）

**UI 现状**：界面硬编码纯中文 —— 34 个 src 文件 ~7500 处汉字（view.rs 1916 /
settings.rs 549 / merge_view.rs 436 …），全仓**零 i18n 脚手架**。加英文 =
字符串全量抽离 + 切换机制 + 双语维护税。

**海外流量现状**（`tasks/calibration-30d.md` 五张快照，09-21 → 10-28，40 天）：

**零国外来源；稳态 ≈4 独立访客/天且衰减。** 「GitHub 被外国人自然检索到」= 零证据。

**买家画像（用户裁决）**：中国付费习惯没有形成，付费指望海外 —— 与自家读数同向
（≈570 阅读 → 24 安装 → 0 付费，全中文渠道）。

**触点现状（10-28 核）**：落地页 `14uncle.github.io` **已是英文**（`lang="en"`）✅；
README = 英文开场 + 中文主体（半英态，待补全）；MS Store 列表 EN-US locale 待核。

## 3. 采访实录（interview-me 四轮）

1. **触发源**：无证据触发 —— 系 v1.5.0 开业日「正经收费软件该有双语」的 convention
   联想（用户 go 确认）。
2. **买家画像**：用户裁「中国付费习惯没有形成；后面分发上海外平台 / GitHub 被外国人
   自然检索到，不支持英文会显得不专业、挡掏钱意愿」——「不专业」是 convention 信号，
   「挡掏钱」是真需求论证，两者同挂一个前提：**海外流量真的会来**。而该前提在证据账
   里目前是零。
3. **排序裁决**：A（先 i18n 再推海外，怕烧一次性首演）vs B（先触点+试投拿读数，
   i18n 挂钟，失效标志前置）——**用户选 B**。
4. **渠道实测定名单**（用户无代理）：MajorGeeks / SnapFiles / Softpedia / FileHippo /
   SourceForge / AlternativeTo / SaaSHub / Portable Freeware 八家提交站可投
   （后六家 WAF 拦 curl 但网络通，浏览器复核）；dev.to 已有备料（distribution-prep
   §2.4② 文案 10）；HN / Reddit / Product Hunt / FileHorse / Uptodown / CNET / Slant
   直连超时或故障，出局。

## 4. 失效标志与复活扳机（开枪前写死）

- **失效标志**：触点英文化 + 试投落地后，到 **2026-11-27**（首单外检钟判读日）——
  海外可辨信号（新 referrer 域名 / 商店市场分布非中文区 / Paddle 买家 locale 非 zh）
  与英文语言类询问**双双为零** ⟹ 「海外自然流量会来」推断**证伪**，i18n **归档**
  （ROADMAP 挂起项转档案注记，提交站名单维持躺平不撤）。
- **复活扳机（任一即触发）**：① 出现可辨海外安装/购买信号；② 任何渠道出现英文用户
  语言类询问或因语言的流失自述 ⟹ i18n 进 spec（五阶段），优先级由当时带宽裁。
  **信号卫生**：爬虫系噪音不算信号——发布事件会触发 GitHub 仓库爬虫（冷邮件 /
  机器人 clones），如 2026-10-28 收到的「增长服务」冷邮件（扫公开提交邮箱群发，
  零产品具体性），与 traffic 里的爬虫 clones 同族，判读时剔除。
- **复盘节奏**：随 11-27 首单外检钟同案判读（执行纪律「失效标志复盘节奏」的兑现点）。

- Product Hunt 级一次性首演：那种渠道烧不起中文 UI；若改主意瞄准它，本裁决的排序
  **翻盘重裁**。
