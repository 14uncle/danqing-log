## 本版更新：高分屏适配

- **修复高 DPI 缩放屏上界面过小**：在 125% / 150% / 200% 系统缩放的屏幕上，
  此前整个界面（文字、间距、控件）会等比缩小到肉眼难用；现在与 100% 缩放观感等比，
  文字按物理像素栅格化、清晰度不劣化
- 运行中改系统缩放 / 拖到另一块不同缩放的屏幕，界面动态跟随，无需重启
- 免费层全部现有功能（打开、搜索、过滤、复制、级别统计）**完整可用、无需激活**
