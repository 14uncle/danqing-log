## 本版更新：高分屏适配

- **修复高 DPI 缩放屏上界面过小**：在 125% / 150% / 200% 系统缩放的屏幕上，
  此前整个界面（文字、间距、控件）会等比缩小到肉眼难用；现在与 100% 缩放观感等比，
  文字按物理像素栅格化、清晰度不劣化
- 运行中改系统缩放 / 拖到另一块不同缩放的屏幕，界面动态跟随，无需重启
- 除渲染与输入坐标的换算外**零功能变化**，免费层功能集与 v1.0.0 完全一致

## 安装

- **便携版**：下载本页的 `danqing-log-v1.0.1-win-x64.zip`，解压即用；同页附 `.sha256` 供校验。
- **微软商店**：v1.0.1 更新随后上架。

## 从 v1.0.0 升级

直接替换二进制即可，配置与数据无格式变化。
