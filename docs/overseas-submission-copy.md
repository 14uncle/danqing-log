## 二、主稿（~100 词，下载站 Description 用）

> LogLens is a native Windows viewer for large log and JSONL files, written in Rust.
> It opens a 1 GiB file in about 0.6 seconds (line index: 92 ms) and stays responsive
> while you search, filter and tail. Regex search with highlighting, a level histogram,
> a JSONL column view with nested expand, GBK/UTF-16 encoding support, bookmarks and
> named workspace sessions — all in a single portable zip under 5 MB. The free tier is
> full-featured for single files and open source (MIT/Apache-2.0). The paid Pro tier
> adds multi-file timeline merge (up to 8 sources), field analytics and export —
> $29 personal / $59 business, perpetual.
>
> Interface language: Simplified Chinese.
