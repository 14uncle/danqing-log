## 本版更新：版本更新提醒

- **新增「有新版本」提醒**：启动后自动检查更新（便携版查 GitHub Releases；
  微软商店版走商店的更新通道）。有新版本时「⚙ 设置」按钮与设置卡「关于」页签
  显示小圆点提示
- 设置 →「关于」中显示更新状态：「前往下载」一键直达最新发布页；
  商店安装版显示「**更新**」，直接拉起系统商店更新流程
- 本版是**第一个带更新检查的版本**——此前版本不会主动提示；从这版起，
  以后每次发新版都能及时知道

## 说明

- 免费层全部现有功能（打开、搜索、过滤、复制、级别统计）**完整可用、无需激活**
- 隐私：便携版启动时仅向 GitHub 发起一次更新查询（固定 UA，无个人信息）；
  商店版**不发起 HTTP**，更新查询走系统商店服务。详见应用内隐私政策
