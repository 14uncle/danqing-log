### 判读（三条）

1. **商店渠道可见流量 ≈ 1.1 浏览/天，远薄于 GitHub 侧（≈4 独立访客/天）**——
   与 pomodoro 首月「商店自然量薄」的结论**完全一致**，本产品还更低一档。
   **「上架即获客」假设第二次被证伪**：商店是分发通道，不是流量来源。
2. **算账基准替换（后续产品直接引用本节数字）**：商店侧 = **1.1 浏览/天 × 18.6% 转化
   ≈ 0.2 安装/天**。相对 pomodoro：浏览持平（43 vs 46）、转化更低（18.6% vs 26%）。
   **安装→付费转化本次无法测算**——add-on 10-30 才上架，本窗口内零购买入口，
   首单外检（11-27）才轮到它。
3. **发布 30 天 vs 稳态**：39 天内唯一事件是 09-21 认证上架本身，无峰值可剥离，
   故 **1.1 浏览/天可直接当稳态日均**用——不像 GitHub 侧须分峰值与长尾。

- 报表 T+1~T+3 延迟：10-30 拉取覆盖完整，无缺窗
- **流程事故（第 2 次，与 GitHub 侧同因）**：期限 10-21，实际 10-30，逾期 9 天。

### 对 i18n 失效标志（2026-11-27）的意义

原本可用的海外证据是「零」；现在变成「商店 2 条安装、GitHub 0」。
**这不足以翻案**（2 条装的是纯中文界面、无后续行为可观测、无付费），但它把
失效标志的判据从「海外需求是否存在」推到了更硬的一层：
**真正要问的是「海外用户愿不愿意用中文界面的付费软件」** —— 而这正是
11-27 之前唯一能测、却在当前数据里测不到的东西。
